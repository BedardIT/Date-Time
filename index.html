Date calculator

This tool has been discontinued

Use Date Calculation in the Windows 11 Calculator app instead.

i
No installation is needed

Calculator is included with Windows 11 and provides the same date calculation options.

Open Date Calculation

Open the Calculator app, then switch to its date mode.

  1. Select Start.
  2. Type Calculator, then open the Calculator app.
  3. Select the navigation menu in the upper-left corner.
  4. Select Date Calculation.

Compare two dates

Find the amount of time between a start date and an end date.

  1. Select Difference between dates.
  2. Choose a date under From.
  3. Choose a date under To.
  4. View the result under Difference.

Find a past or future date

Add or subtract a set number of years, months, or days.

  1. Select Add or subtract days.
  2. Choose the starting date.
  3. Select Add or Subtract.
  4. Enter the number of years, months, and days.
  5. View the result under Date.
